# Matthew-S-Chiasson-Breast-Cancer-Classification-AI
A personal project to practice binary classification using Convolutional Neural Networks (CNNs). This project classifies breast cancer cell data as _malignant_ or _benign_ using supervised learning.

Originally built in 2023, added to GitHub in 2025.

# Overveiw

This project was created to help me:

- Understand the fundamentals of binary classification using CNNs

- Gain hands-on experience with PyTorch

- Explore how to work with real-world datasets

- Build a reference I can revisit for future AI/ML work

The dataset was sourced from Kaggle, and my implementation closely follows several community examples. However, I made a point to annotate, explain, and modify the code to deepen my understanding and tailor it to my learning process.
